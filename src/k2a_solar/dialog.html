1. Объект: координаты и север

Строку координат из Google Maps («47.8388, 35.1396») можно вставить в поле широты целиком — разделится сама. Север — угол от зелёной оси Y по часовой стрелке. «Север по линии»: проведите на подложке линию с юга на север, выделите её и нажмите; стрелка легла на юг — «Север +180°». Всё пишется в настройки солнца модели (Геопозиция, Тени): по ним считаются тени SketchUp, зазор рядов по солнцу и ряды «по сторонам света». Уже стоящие массивы не перестраиваются — разместите их заново.

4. Обход препятствий и тип крепления

Ручная правка: выделите массив (группу «PV_Скат…»), «Добавить панель вручную» — щелчки по скату; панель прилипает к ряду и соседям. Удалили или передвинули панели внутри группы — «Пересобрать крепёж» («Пересчитать» в режиме «Только расстановка»).
Только расстановка: панели, их число и мощность, без профиля, опор и балласта. «Высота над кровлей» — на сколько панель поднята над скатом. «Рядов в полосе» больше 1 — ряды ставятся группами, между группами — «Проход». «Пересчитать» обновляет число панелей выделенных массивов и убирает из них крепёж, если он был.
«Пересобрать крепёж» берёт настройки системы из окна: систему, профиль, число линий профиля, крепление, шаг опор, зазор кровли, балласт — для выделенных массивов (или единственного в модели). Систему так можно сменить только между скатной и Block при панелях без наклона; переход на балластную или наземную меняет раскладку — массив нужно разместить заново.
Полосы: «Рядов в полосе» больше 1 — ряды ставятся группами с зазором «Между рядами», между группами — «Проход». «Поперёк ряда» — два профиля под каждой стопкой панелей вдоль ската; для панелей без наклона к кровле. «Линий профиля: 3» — третья линия посередине панели, с прижимами и опорами, при любой укладке. «Шаг опор» при саморезах — шаг точек крепления (по умолчанию 700 мм), один саморез на точку, под каждый — 50 мм битумной ленты.
Системы RUDNIK. SolarSet: два профиля на ряд из стандартных отрезков 1230–3100 мм. Balast Південь: панель альбомом на трёх треугольниках, по 2 блока на треугольник, спойлер, сполучники; зазор между рядами — «Между рядами», по умолчанию 700 мм. Balast Схід-Захід: ячейка — «домик» из двух панелей; нормы расхода по аналогии, поставщиком не подтверждены. Landing: стол из двух панелей книгой по высоте, наклон 30°, рамы с шагом не больше 2800 мм, консоль прогона 825 мм. Block: панель лежит без наклона на блоках L 310 высотой 50 мм под каждой точкой прижима, две линии на ряд; заклёпок 4 на блок и лента под блок — допущение. Балластные — только на плоской кровле; ветровая нагрузка не считается.
Окно задаётся в солнечном времени: 12 — истинный полдень. «С 12 до 12» — расчёт только на полдень. Скат с уклоном до 5° считается плоской кровлей.
Выделите один или несколько скатов крыши (Shift + клик) либо группу крыши целиком. Дымоходы и трубы на крыше плагин обойдёт автоматически.
