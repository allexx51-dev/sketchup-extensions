# Дополнения к SketchUp

Сайт автора: [alexkaminsky.me](https://alexkaminsky.me)

Три расширения для SketchUp, написанные для собственной работы: чтобы делать быстрее то, что приходится делать часто.

**Выкладывается как есть.** Делалось для облегчения и ускорения своей работы, не ради выгоды. Лицензия MIT: кому нравится — пользуется и улучшает, кому не нравится — претензии не принимаются. Гарантий нет никаких, ответственность за результат на том, кто пользуется (это и есть смысл лицензии, полный текст — в [LICENSE](LICENSE)).

## Что внутри

| Файл | Что делает |
|---|---|
| [`k2a_elektrika_0.5.1.rbz`](dist/k2a_elektrika_0.5.1.rbz) | **Электрика (трассы).** Расстановка розеток, выключателей, светильников, выводов и щита на стены и потолок; механизмы серии 71 мм сами встают в блок под общую рамку. Кабель между двумя механизмами прокладывается автотрассой стена — потолок — стена, трассы раскладываются по уровням без перехлёстов. Сегмент трассы можно сдвинуть вручную, соседние достроятся под прямым углом. Спецификация: кабель по маркам с запасом, механизмы, рамки; выгрузка в CSV. Своя библиотека устройств, в том числе из компонентов модели. |
| [`k2a_profile_1.7.rbz`](dist/k2a_profile_1.7.rbz) | **Профиль по линиям.** По выделенным рёбрам каркаса строит квадратный или прямоугольный профиль нулевой толщины. Узлы: на ус или встык, сквозные — стойки или балки, наклонные элементы режутся по грани соседа. Длина по умолчанию — точно по направляющим: ни одно ребро профиля не выходит за конец линии; режим «с выступом» оставляет углы реза за узлом. В имени каждой группы — сечение и длина. Своя панель с кнопкой, команда есть и в контекстном меню при выделенных рёбрах. |
| [`k2a_angledim_1.3.rbz`](dist/k2a_angledim_1.3.rbz) | **Угловой размер.** Вершина, точка на первой стороне, точка на второй, положение дуги (или радиус с клавиатуры). Дуга со стрелками, выносные линии, подпись в градусах; точность, разделитель, тег и длина стрелок — в настройках, запоминаются между запусками SketchUp. Своя панель: размер и настройки. |

Исходники в распакованном виде — в папке [`src/`](src/). Файлы `.rbz` в [`dist/`](dist/) — те же исходники, упакованные для установки.

## Установка

SketchUp → **Extensions → Extension Manager → Install Extension** (Расширения → Менеджер расширений → Установить расширение) → выбрать нужный `.rbz`. После установки команды появляются в меню **Extensions** и на панелях инструментов: у «Электрики» их две, у «Профиля» и «Углового размера» — по одной.

Писалось под SketchUp 2021 и новее (Ruby 2.7).

Обновление: перед установкой новой версии удалите прежнюю в Менеджере расширений и перезапустите SketchUp, после установки — перезапустите ещё раз. Иначе SketchUp продолжит выполнять уже загруженный старый код. Прежние версии назывались с префиксом AK (`ak_*.rbz`); их тоже нужно удалить, иначе команды появятся дважды.

## Замечания

- Интерфейс только на русском.
- «Электрика» хранит настройки (пол, потолок, отступы, запасы) в модели, а библиотеку своих устройств — в настройках SketchUp и копией в модели, чтобы модель открывалась на другом компьютере.
- Марки кабеля в «Электрике» заданы списком в начале `main.rb` (`CABLES`); нужен другой — можно ввести вручную в окне прокладки или дописать в список.
